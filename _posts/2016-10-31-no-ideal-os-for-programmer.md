There is no ideal OS for a programmer, for both work and home.

Written from a JVM developer's perspective, probably similar for all non-.NET languages.

## Windows
* The most popular one.
* No doubt it's great for home use - it's tuned for that.
* For work, it's just not from the Unix family and has no central repository for development tools. Most servers run Linux, which is cheap, reliable and tuned for constant work.
* You have everything you need to work here, but it's not easy to set up and maintain...
* Windows 10 has virtual desktops, at last!

## Linux
* Very good for work. What you learn here, you can use on the server side. Tools are easy to install and maintain.
* It sucks for home use... The GUI environment isn't well tested. It shares its heart with servers, but that's not enough. From time to time workarounds are needed.

If you want fancy features that development doesn't need... then you have to rely on the work of unpaid developers. If they haven't done what you need, no private business will do it for you. Compared to Windows, there is no big group of Linux users who pay for... anything.

## macOS
* Tends to be the best compromise between work and home use. It's designed for regular users and it's Unix-based.
* For work it's a bit worse than Linux. The default repositories are tuned for regular users, right?
* 3D gaming, support for custom hardware, a great non-development experience - it's all there for you.
* Apple shapes new global trends with its products.

But...

* You have to learn a new keyboard layout. Ctrl is Cmd, Super is... argh, changing habits is hard.
* It's so expensive. In Poland it's even 30% more expensive than in the US.
* Big user groups exist only in rich countries. Want a gadget? Ship it from the USA.
* Apple delivers new features with big delays on purpose, for profit... e.g. Touch ID appeared 12 years after the first biometric readers appeared on the laptop market, and 3 years after Apple put it in the iPhone.
* Custom hardware often doesn't work with Macs unless it's designed specifically for them. That raises the price of the whole setup.
* No numeric keypad in 15-inch MacBooks. If you don't like the keyboard, well... you can use an external one ;P.
* In 2016: do you want Touch ID? OK, then say goodbye to the Esc and F1-F12 keys... Why? Because here a developer is a second-class citizen. Regular users will benefit more from the dynamic touch panel. Lenovo Windows laptops have a similar story with the F keys.

## Now you see
There is no clear winner here. If you have another solution, please share it in a comment.

For now I use Windows 10 and Linux (Ubuntu with Unity or MATE, Ubuntu Server or CentOS). With some virtualization skills and spare RAM, I get the best of both worlds.
