I wanted to learn the basics of ZIO 2 and Scala 3, so I made a little project for that.

![ZIO logo](https://user-images.githubusercontent.com/6271645/214564924-cd9306ed-74b4-4d61-92f5-a9898d5d8648.png)

## Challenge
There were no articles on how to use ZIO 2, Scala 3, Tapir, Doobie, Postgres and Docker together.

Most how-tos were about ZIO 1 or Scala 2, so it was a challenge to bump all the versions and dig into the migration guides.

A surprise for me was the custom versioning scheme of the interoperability library between Cats and ZIO, which was needed to use Doobie. Two newer versions were made for a pair of ZIO and Cats versions that weren't the newest. Take that into account when using plugins for library maintenance.

You can find how I solved it [here](https://github.com/kastoestoramadus/affirmations).
